

## Tonnetz grid

The Tonnetz is a 2-dimensional mesh which maps the tonal landscape of western music. It was created back in 1739 by Leonhard Euler as a way to graphically represent the ideas behind Neo-Riemannian theory.

Knowing the pattern:

1. You’ll be able to quickly find the notes to any chord.
2. You’ll be able to identify what notes are in each key.
3. You’ll be able to transpose chord progressions into other keys.
4. You’ll be able to find relative major and minor chords
5. You’ll be able to identify substitute chords with common chord tones
6. You can find many chord options that fit a common note, perhaps the melody note.

### How the Tonnetz is Constructed

Let’s have a look at the Tonnetz - a mesh of triangles with notes at intersecting points. The edges of the triangles form lines, which represent intervals between notes. The mesh knows no bounds, stretching to infinity in all directions.
