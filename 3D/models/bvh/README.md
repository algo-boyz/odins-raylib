# BVHView
is a [.bvh animation](https://research.cs.wisc.edu/graphics/Courses/cs-838-1999/Jeff/BVH.html) viewer built with [Raylib](https://www.raylib.com/) ported to Odin from the legendary BVHView [C source](https://github.com/orangeduck/BVHView) of Daniel Holden aka OrangeDuck.

https://github.com/orangeduck/BVHView/assets/177299/9f976284-02c1-4a14-bca4-b8b3d7c9a774

## How to make your own bvh animation from video?

Check out [video2BVH](https://github.com/KevinLTT/video2bvh) or the [CMU Mocap](https://github.com/una-dinosauria/cmu-mocap) dataset on Github.

- [smpl2bvh](https://github.com/KosukeFukazawa/smpl2bvh)
- [AMASS](https://github.com/KosukeFukazawa/CharacterAnimationTools#13-load-animation-from-amass)
